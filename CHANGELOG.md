# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-08-02

### Added

- Create a habit experiment with a cue, action, and length.
- Record each day with one clear control.
- Add a short note for context.
- Review completion across the latest seven days.
- Seed the first run with a local sample experiment.
- Store experiments and check-ins in SQLite.
- Add deterministic tests for the domain, date tools, and storage maps.
- Add a GitHub Actions workflow for format, analyze, and test checks.
